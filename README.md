# 궁극의 노후 절세 마스터플랜 (2026 검증판)

연금 · ISA · 미국주식 직투를 활용한 노후 절세 통합 전략을, **나이별 · 투자금 규모별 · 시간 흐름별** 액션으로 한눈에 정리한 사이트입니다. **Vercel**로 배포합니다(정적 사이트 + `/api` 서버리스 함수).

🔗 **사이트:** `https://<프로젝트>.vercel.app` (Vercel 배포 후)

## 구성

- **0단계 — 시간 시계 작동:** 오늘 연금계좌 1만 원 입금으로 5년 타이머 켜기
- **1단계 — 폭포수 납입:** 연금 900 → ISA 2,000 → 미장 직투
- **2단계 — 건보료 레이더 회피:** 부부 명의 분산, 배당 999만 원 컷오프
- **3단계 — 현금흐름 수확:** ISA 원금 출금, 풍차돌리기, 저율 연금 개시
- **3가지 뷰:** 나이대별 / 투자금 규모별 / 시간 흐름별 액션
- **절세 기술 모음** + **실전 포트폴리오 표**
- **2026 정확성 검토:** 개정세법 반영(이월과세, 연금 1,500만 원, ISA 전환 추가공제)

## 배포 (Vercel)

정적 사이트 + 서버리스 함수(`api/market-insider.js`)라 Vercel에 import 하면 한 번에 배포됩니다.
**`main` 브랜치에 push하면 자동 재배포**됩니다. 자세한 단계는 **[`VERCEL_SETUP.md`](./VERCEL_SETUP.md)** 참고.

- 라이브 '시장 전체 내부자 매도' 차트는 OpenInsider(SEC Form 4) 기반이라 **API 키가 필요 없습니다**.
